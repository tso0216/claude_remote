## Slide 20 — Exercise 1 — Decode the ALU Control

Exercise 1 — Decode the ALU Control

Given the following control information:

ALUOp = 10      funct = 100010      ALU control = 0110

(a) Identify which value is 2-bit, 6-bit, and 4-bit.

(b) Determine the ALU operation.

(c) Determine the corresponding R-type instruction.

Answer

(a) ALUOp: 2-bit;  funct: 6-bit;  ALU control: 4-bit

(b) ALU operation = SUB

(c) funct = 100010 corresponds to the R-type instruction sub.

Key Point:

ALUOp identifies the operation class; funct selects the R-type operation; ALU Control gives the final ALU command.


## Slide 21 — Exercise 2 — Determine R-Type Control Signals

Exercise 2 — Determine R-Type Control Signals

Consider the instruction:  and $t0, $t1, $t2

(a) Determine RegDst, ALUSrc, and RegWrite.

(b) Determine MemRead, MemWrite, and MemtoReg.

(c) Determine ALUOp. Why is the funct field still needed?

Answer

(a) RegDst = 1,  ALUSrc = 0,  RegWrite = 1

(b) MemRead = 0,  MemWrite = 0,  MemtoReg = 0

(c) ALUOp = 10. The funct field specifies the exact R-type ALU operation, which is AND here.

Key Point:

R-type instructions use ALUOp = 10, while the funct field specifies the exact ALU operation.


## Slide 22 — Exercise 3 — Find the Control Error

Exercise 3 — Find the Control Error

A student proposes the following control settings for a beq instruction:

ALUSrc = 0      ALUOp = 01      RegWrite = 1

MemRead = 0      MemWrite = 0

(a) Which control value is incorrect?

(b) Correct the value.

(c) Explain what could go wrong if the incorrect value were used.

Answer

(a) RegWrite = 1 is incorrect.

(b) RegWrite should be 0.

(c) beq does not write a result to the Register File. Enabling RegWrite could cause an unintended register write.

The other listed control values are consistent with beq.

Key Point:

Check each control signal by asking whether that CPU operation is actually required by the instruction.
