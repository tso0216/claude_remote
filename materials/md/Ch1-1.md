## Slide 2 — Below Your Program

§1.3 Below Your Program

- Application software
  - Written in high-level language
- System software
  - Compiler: translates HLL code to machine code
  - Operating System: service code
    - Handling input/output
    - Managing memory and storage
    - Scheduling tasks & sharing resources
- Hardware
  - Processor, memory, I/O controllers
Q1. Can a CPU directly execute a C program?

A1. No. The program must first be translated into machine code.

## Slide 3 — Levels of Program Code

- High-level language
  - Level of abstraction closer to problem domain
  - Provides for productivity and portability
- Assembly language
  - Textual representation of instructions
- Hardware representation
  - Binary digits (bits)
  - Encoded instructions and data
Q2. Which representation is closest to the hardware: C, assembly language, or machine language?

A2. Machine language, because it represents instructions directly in binary form that the processor can execute.

## Slide 4 — Abstractions

The BIG Picture

- Abstraction helps us deal with complexity
  - Hide lower-level detail
- Instruction set architecture (ISA)
  - The hardware/software interface
- Application binary interface
  - The ISA plus system software interface
- Implementation
  - The details underlying and interface
Q3. If we write result = 5 * 8;, what might the computer need to do behind the scenes?

A3. 1) Load the numbers, 2) Perform the multiplication, 3) Store the result. Abstraction allows the programmer to ignore these lower-level steps.


## Slide 5 — Components of a Computer

§1.4 Under the Covers

The BIG Picture

- Same components for
  all kinds of computer
  - Desktop, server,
    embedded
- Input/output includes
  - User-interface devices
    - Display, keyboard, mouse
  - Storage devices

Q4. What everyday devices can be considered computers?

A4. smartphones, smartwatches, game consoles, smart TVs, Wi-Fi routers, and even washing machines or cars. They all contain basic computing components such as a processor, memory, and I/O.

## Slide 6 — Inside the Processor (CPU)

- Datapath: performs operations on data
- Control: sequences datapath, memory, ...
- Cache memory
  - Small fast SRAM memory for immediate access to data
Q5. If the CPU needs to add two numbers, which part is mainly responsible for performing the operation?

A5. The Datapath.

## Slide 8 — Exercise 1 | Who Does What?

Exercise 1 | Who Does What?

A program calculates the average of three numbers. Who is mainly responsible for each task?

1. Translating the program into machine code
2. Managing memory and other system resources
3. Executing the machine instructions

Answer

- Compiler — translates the program into machine code.
- Operating System — manages memory and system resources.
- Processor — executes the machine instructions.
Key Point: Distinguish the roles of the Compiler, Operating System, and Processor.


## Slide 9 — Exercise 2 | Abstraction in Everyday Computing

Exercise 2 | Abstraction in Everyday Computing

When you save a file, you simply click “Save.” What lower-level details can be hidden from you by abstraction? Give two examples.

Possible Answers

Where the data is physically stored

How the operating system accesses the storage device

How the data is represented in binary

How the hardware transfers the data

Key Point | Abstraction hides lower-level details that are unnecessary at the current level.
