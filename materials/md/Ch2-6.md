## Slide 6 — Producing an Object Module

- Assembler (or compiler) translates program into machine instructions
- Provides information for building a complete program from the pieces
  - Header: described contents of object module
  - Text segment: translated instructions
  - Static data segment: data allocated for the life of the program
  - Relocation info: for contents that depend on absolute location of loaded program
  - Symbol table: global definitions and external refs
  - Debug info: for associating with source code

## Slide 8 — Linking Object Modules

- Produces an executable image
  1.	Merges segments

  2.	Resolve labels (determine their addresses)

  3.	Patch location-dependent and external refs

- Could leave location dependencies for fixing by a relocating loader
  - But with virtual memory, no need to do this
  - Program can be loaded into absolute location in virtual memory space

## Slide 11 — C Sort Example

§2.13 A C Sort Example to Put It All Together

- Illustrates use of assembly instructions for a C bubble sort function
- Swap procedure (leaf)
  void swap(int v[], int k)
  {
    int temp;
    temp = v[k];
    v[k] = v[k+1];
    v[k+1] = temp;
  }

  - v in $a0, k in $a1, temp in $t0

## Slide 12 — The Procedure Swap

swap: sll $t1, $a1, 2   # $t1 = k * 4

add $t1, $a0, $t1 # $t1 = v+(k*4)

#   (address of v[k])

lw $t0, 0($t1)    # $t0 (temp) = v[k]

lw $t2, 4($t1)    # $t2 = v[k+1]

sw $t2, 0($t1)    # v[k] = $t2 (v[k+1])

sw $t0, 4($t1)    # v[k+1] = $t0 (temp)

jr $ra            # return to calling routine

## Slide 28 — Exercise 1 | Pseudoinstruction Expansion

Exercise 1 | Pseudoinstruction Expansion

A programmer writes:
    move $t0, $s0
    bgt  $t0, $s1, L1
Assume $at can be used by the assembler.
(a) Expand both pseudoinstructions into actual MIPS instructions.
(b) How many actual MIPS instructions are generated in total?
(c) Which register is used by the assembler when expanding bgt?

Answer

(a) move $t0, $s0  →  add $t0, $zero, $s0

bgt $t0, $s1, L1  →
    slt $at, $s1, $t0
    bne $at, $zero, L1

(b) 3 actual MIPS instructions

(c) $at — assembler temporary

Key Point: One pseudoinstruction may expand into one or more actual MIPS instructions.


## Slide 29 — Exercise 2 | Procedure Swap Analysis

Exercise 2 | Procedure Swap Analysis

swap:
    sll  $t1, $a1, 2
    add  $t1, $a0, $t1
    lw   $t0, 0($t1)
    lw   $t2, 4($t1)
    sw   $t2, 0($t1)
    sw   $t0, 4($t1)
    jr   $ra
Assume $a0 = 1000, $a1 = 2, Memory[1008] = 15, and Memory[1012] = 25.
(a) What address is calculated in $t1?
(b) What values are loaded into $t0 and $t2?
(c) What are Memory[1008] and Memory[1012] after the procedure finishes?

Answer

(a) $t1 = 2 × 4 + 1000 = 1008

(b) $t0 = 15, $t2 = 25

(c) Memory[1008] = 25, Memory[1012] = 15

Key Point: The swap procedure combines array addressing, load/store instructions, and procedure return in one complete example.


## Slide 30 — Exercise 3 | Trace a MIPS Loop

Exercise 3 | Trace a MIPS Loop

Assume:
$s0 = 1000,  $s1 = 0,  $s2 = 3
Memory[1000] = 5, Memory[1004] = 8, Memory[1008] = 12
loop:  lw   $t0, 0($s0)
       add  $s1, $s1, $t0
       addi $s0, $s0, 4
       addi $s2, $s2, -1
       bne  $s2, $zero, loop
(a) How many iterations are executed?
(b) What values are loaded into $t0?
(c) What are the final values of $s0, $s1, and $s2?

Answer

(a) 3 iterations

(b) $t0: 5 → 8 → 12

(c) $s0 = 1012, $s1 = 25, $s2 = 0

Key Point: Tracing a loop requires following memory accesses, register updates, and branch conditions across iterations.


## Slide 31 — Exercise 4 | Integrated Instruction Analysis

Exercise 4 | Integrated Instruction Analysis

Given:
lw   $t0, 8($s0)
add  $t1, $t0, $s1
slt  $t2, $t1, $s2
bne  $t2, $zero, L1
jal  update

(a) Classify each instruction as Data Transfer, Arithmetic, Comparison/Branch, or Jump/Procedure.
(b) Identify the format of each instruction: R, I, or J.
(c) Which instruction accesses memory, performs the comparison, and calls a procedure?

Answer

lw   → Data Transfer, I-format

add  → Arithmetic, R-format

slt  → Comparison, R-format

bne  → Conditional Branch, I-format

jal  → Jump / Procedure, J-format

(c) Memory access → lw, Comparison → slt, Procedure call → jal

Key Point: A MIPS program combines different instruction classes and formats for data, computation, control flow, and procedures.
