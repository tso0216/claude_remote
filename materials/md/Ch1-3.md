## Slide 2 — Measuring Execution Time

- Elapsed time
  - Total response time, including all aspects
    - Processing, I/O, OS overhead, idle time
  - Determines system performance
- CPU time
  - Time spent processing a given job
    - Discounts I/O time, other jobs’ shares
  - Comprises user CPU time and system CPU time
  - Different programs are affected differently by CPU and system performance

## Slide 16 — Exercise 1 | Clock Rate and CPU Time

Exercise 1 | Clock Rate and CPU Time

A processor operates at 3.2 GHz. A program requires 12.8 × 10⁹ clock cycles.

(a) Calculate the CPU execution time.

(b) If clock cycles are reduced by 25%, calculate the new CPU execution time.

Answer

(a) CPU Time = (12.8 × 10⁹) / (3.2 × 10⁹) = 4 s

(b) New Cycles = 0.75 × 12.8 × 10⁹ = 9.6 × 10⁹

New CPU Time = (9.6 × 10⁹) / (3.2 × 10⁹) = 3 s

Key Point: With a fixed Clock Rate, CPU Time changes in direct proportion to Clock Cycles.


## Slide 17 — Exercise 2 | Clock Rate vs. Clock Cycles

Exercise 2 | Clock Rate vs. Clock Cycles

Computer A: CPU Time = 8 s, Clock Rate = 2.5 GHz.

Computer B: Clock Rate = 4.0 GHz, but requires 30% more clock cycles.

(a) Calculate CPU Time for Computer B.

(b) Calculate the speedup of B over A.

Answer

Cycles_A = 8 × 2.5 × 10⁹ = 20 × 10⁹

Cycles_B = 1.3 × 20 × 10⁹ = 26 × 10⁹

(a) CPU Time_B = 26 / 4 = 6.5 s

(b) Speedup = 8 / 6.5 ≈ 1.23×

Key Point: A higher Clock Rate does not guarantee the same performance gain if Clock Cycles also change.


## Slide 18 — Exercise 3 | Instruction Mix and Average CPI

Exercise 3 | Instruction Mix and Average CPI

Class A: CPI = 1, IC = 4 × 10⁶

Class B: CPI = 2, IC = 3 × 10⁶

Class C: CPI = 4, IC = 1 × 10⁶     Clock Rate = 2 GHz

(a) Calculate average CPI.   (b) Calculate CPU execution time.

Answer

Total IC = 8 × 10⁶

(a) CPI_avg = [4(1) + 3(2) + 1(4)] / 8 = 1.75

(b) Clock Cycles = 8 × 10⁶ × 1.75 = 14 × 10⁶

CPU Time = 14 × 10⁶ / 2 × 10⁹ = 7 ms

Key Point: Instruction Mix determines Average CPI, which affects Clock Cycles and CPU Time.

## Slide 20 — Exercise 5 | Integrated Performance Analysis

Exercise 5 | Integrated Performance Analysis

Original: CPU Time = 1.6 s, IC = 2.0 × 10⁹, CPI = 2.0, Clock Rate = 2.5 GHz.

A: IC ↓ 30%, CPI ↑ 10%.     B: Clock Rate ↑ to 3.5 GHz.

(a) Calculate CPU Time after A.   (b) Calculate CPU Time after B.

(c) Which optimization is better? Support with speedup.

Answer

(a) A: IC = 1.4 × 10⁹, CPI = 2.2 → CPU Time = 1.232 s

(b) B: CPU Time = (2.0 × 10⁹ × 2.0) / (3.5 × 10⁹) ≈ 1.143 s

(c) Speedup_A ≈ 1.30×; Speedup_B ≈ 1.40×

Optimization B provides better performance.

Key Point: CPU Time must be evaluated using IC, CPI, and Clock Rate together.
