## Slide 19 — Branch Instructions

- Read register operands
- Compare operands
  - Use ALU, subtract and check Zero output
- Calculate target address
  - Sign-extend displacement
  - Shift left 2 places (word displacement)
  - Add to PC + 4
    - Already calculated by instruction fetch

## Slide 29 — Exercise 2 — Debug the Datapath

Exercise 2 — Debug the Datapath

For  lw $t0, -8($t1):

$t1 = 0x10000020     Memory[0x10000018] = 25

A student traces the datapath as follows:

Immediate = 0xFFF8

Sign-Extended Immediate = 0x0000FFF8
ALU Result = 0x10010018

Write Data = 0x10010018

Find the errors and correct them.

Answer

There are three errors:

1.  Sign-Extended Immediate = 0xFFFFFFF8

2.  ALU Result = 0x10000018

3.  Write Data = 25

The ALU Result is the memory address. For lw, the value read from memory is written back to $t0.

Trace the data flow in order:

sign extension → address calculation → memory read → write-back.


## Slide 30 — Exercise 3 — Complete Branch Tracing

Exercise 3 — Complete Branch Tracing

Given:

PC = 0x00400080     $t0 = 20     $t1 = 20

Instruction:  beq $t0, $t1, -4

(a) PC + 4          (b) ALU Result and Zero
(c) Sign-Extended Immediate and Shifted Offset
(d) Branch Target and Next PC

Answer

(a)  PC + 4 = 0x00400084

(b)  ALU Result = 0,   Zero = 1

(c)  Sign-Extended Immediate = 0xFFFFFFFC
      Shifted Offset = 0xFFFFFFF0 (-16)

(d)  Branch Target = 0x00400074,   Next PC = 0x00400074

Branch tracing combines comparison and target-address calculation to determine the Next PC.
