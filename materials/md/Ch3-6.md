## Slide 7 — Common Exception Types

- Undefined Opcode: when the CPU encounters an invalid or unsupported instruction
- Arithmetic Overflow: when a signed arithmetic result exceeds the representable range.
- System Call: when a program executes syscall to request an operating system service.

## Slide 19 — Exception Properties

- Restartable exceptions allow execution to resume after handling the exception.
- The EPC stores the address of the instruction associated with the exception.
- The exception handler determines whether execution can resume.
- If restartable, the CPU can return to the appropriate instruction.
- Otherwise, the program may be terminated.

## Slide 24 — Concluding Remarks

§4.16 Concluding Remarks

- The processor executes instructions through the fetch, decode, execute, and PC update steps.
- Combinational and sequential logic support datapath operations and clocking.
- The datapath uses registers, the ALU, and memory to execute different instruction types.
- The control unit generates control signals to coordinate datapath operations.

## Slide 27 — Exercise 1 — Single-Cycle Processor Performance

Exercise 1 — Single-Cycle Processor Performance

Answer

(a) Clock Period

The clock period is determined by the slowest instruction (lw).

- Processor A: 800 ps
- Processor B: 700 ps
(b) Execution Time

Total Instruction Count = 4,000 + 2,000 + 1,000 + 3,000 = 10,000

Since CPI = 1:

- Processor A: 10,000 × 800 ps = 8 μs
- Processor B: 10,000 × 700 ps = 7 μs
(c) Speedup

Speedup = 8/7 = 1.143

Processor B is approximately 14.3% faster than Processor A.

Key Point:

In a single-cycle processor, all instructions share the same clock period, which is determined by the slowest instruction.

## Slide 29 — Exercise 2 — Exception Handling Procedure

Exercise 2 — Exception Handling Procedure

Answer

- Detect Exception: Arithmetic overflow occurs at 0x00400024.
- Save EPC: EPC ← 0x00400024.
- Set Cause: Cause ← 1 (Arithmetic Overflow, using the simplified course encoding).
- Redirect PC: PC ← 0x80000180.
- Execute Handler: The handler reads Cause and determines the appropriate action.
- Terminate Program: Assume the overflow cannot be corrected; execution does not resume.
Key Point:

Exception handling saves the faulting instruction address in EPC, records the exception type in Cause, and redirects PC.
