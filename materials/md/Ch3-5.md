Q1. Consider the following instruction: sub $t0, $t1, $t2

Given $t1 = 20 and $t2 = 8, determine:

The values of RegDst, ALUSrc, MemtoReg, and RegWrite.

(b) The values of ALUOp and ALU Control.

A1.

(a) RegDst = 1, ALUSrc = 0, MemtoReg = 0, RegWrite = 1.

(b) ALUOp = 10, ALU Control = 0110 (SUB).

(c) The ALU performs 20 − 8 = 12. The result is written into $t0, so $t0 = 12.

Q2. Consider the instruction lw $t0, 8($t1).

Which control signals must be set to 1 to calculate the effective address, read data from memory, and write the loaded value into $t0?

A2.

ALUSrc = 1, MemRead = 1, MemtoReg = 1, and RegWrite = 1.

ALUSrc selects the immediate offset for address calculation, MemRead enables memory reading, MemtoReg selects the memory data, and RegWrite enables writing the loaded value into $t0.

Q3. A MIPS processor executes an instruction with the following control signals:

RegWrite = 0, MemRead = 0, MemWrite = 1, ALUSrc = 1, ALUOp = 00 What type of instruction is being executed, and how does the processor use the ALU result?

A3.

The processor is executing a Store (sw) instruction.

The ALU adds the base register value and the sign-extended immediate offset to calculate the effective memory address. The processor then writes the second register's data into that memory address.

Q4. Consider the instruction beq $t1, $t2, 12, where $t1 = 25, $t2 = 25, and PC = 0x00400020. Given Branch = 1, determine the values of Zero and PCSrc, and calculate the Next PC.

A4.

Zero = 1 because the two register values are equal.

PCSrc = Branch AND Zero = 1 AND 1 = 1.

PC + 4 = 0x00400024.

Branch Offset = 12 × 4 = 48 = 0x30.

Branch Target = 0x00400024 + 0x30 = 0x00400054.

Therefore, Next PC = 0x00400054.

Q5. A processor executes a Jump instruction with Jump = 1, Branch = 0, and Zero = 0.

If PC + 4 = 0x00400024 and the Jump Target is 0x00400080, determine the value of PCSrc and explain which address becomes the Next PC.

A5.

PCSrc = Branch AND Zero = 0 AND 0 = 0

The Branch MUX selects PC + 4 = 0x00400024.

However, Jump = 1 causes the Jump MUX to select the Jump Target.

Therefore, Next PC = 0x00400080.

Exercise 2 — Control Signal Fault Analysis

Given lw $t0, 8($t1), with $t0 = 4, $t1 = 1000, Mem[1004] = 40, and Mem[1008] = 25.

Determine the final value of $t0 for each independent control signal error:

ALUSrc = 0

(b) RegWrite = 0

Answer

- Address = 1000 + 4 = 1004 → $t0 = 40
- (b) Register write disabled → $t0 = 4
- (c) ALU result selected → $t0 = 1008

Incorrect control signals affect address calculation, register writing, and write-back selection.

Mem[1012] is updated to 35.

Key Point:

## Slide 32 — Exercise 5 — Jump Target Reconstruction

Exercise 5 — Jump Target Reconstruction

A MIPS processor executes j 0x00400080 with PC = 0x00400020.Given Jump = 1 and PCSrc = 0, determine:

(a) The 26-bit jump address field.

(b) The 32-bit Jump Target formed by concatenation.

(c) The final Next PC.

Answer

(a) Jump address field = 0x00100020.

(b) Jump Target = {(PC + 4)[31:28], Instruction[25:0], 2'b00} = 0x00400080.

(c) Jump = 1 selects the Jump Target. Therefore, Next PC = 0x00400080.

Key Point:

A jump target combines the upper 4 bits of PC + 4, the 26-bit address field, and two trailing zeros.
