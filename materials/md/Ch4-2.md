## Slide 5 — Instruction fetch (Cont.)

Q1. A lw instruction has just completed the IF stage.

Which information must be stored in the IF/ID pipeline register for the next stage?

ALU result and destination register number

B. Instruction and PC + 4

C. Memory read data and RegWrite

D. Register operands and sign-extended immediate

A1.

B. Instruction and PC + 4

Needed for decoding and register selection in ID.

PC + 4 is preserved for instructions in later stages.

Register operands and sign-extended immediate are generated during ID.

## Slide 16 — Wrong Register Number

Q4. Consider the following instructions in a five-stage pipeline without stalls

I1: lw  $t1, 4($s0)

I2: add $t2, $s1, $s2

I3: sub $t3, $s3, $s4

I4: and $t4, $s5, $s6

When I1 reaches the WB stage, I4 is in the ID stage. If the destination register number is incorrectly taken from the current ID stage, which register will be written instead of $t1?

A4.

$t4

The WB stage would incorrectly use the destination register number of I4 ($t4). The correct destination register number ($t1) must travel with I1 through the pipeline registers.

## Slide 23 — Exercise 1 — Pipeline Register Consistency

Exercise 1 — Pipeline Register Consistency

Consider three instructions in a five-stage pipeline:

I1: lw   $t0, 8($s0)

I2: add  $t1, $s1, $s2

I3: sub  $t2, $s3, $s4

ID/EX

EX/MEM

MEM/WB

I3

I2

I1

EX/MEM contains ALU Result = 45, but its destination register number is $t2. Identify the incorrect field and provide the correct value.

Answer

Incorrect field: EX/MEM destination register number.

Correct value: $t1 (the destination register of I2).

Key Point:

Data and register numbers must belong to the same instruction.


## Slide 24 — Exercise 2 — Pipeline Stage Timing

Exercise 2 — Pipeline Stage Timing

Consider a five-stage pipeline without stalls or forwarding:

I1: add  $t0, $s0, $s1

I2: sub  $t2, $t0, $s2

I3: and  $t3, $s3, $s4

When I2 is in the ID stage, identify the stages occupied by I1 and I3. Has I1 already written its result to $t0?

Explain your answer based on the five-stage pipeline sequence.

Answer

I1: EX;  I2: ID;  I3: IF.

No. I1 writes $t0 during WB, which occurs later.

Key Point:

Instructions overlap in different stages; WB occurs after EX and MEM.


## Slide 25 — Exercise 3 — Reverse Pipeline Reasoning

Exercise 3 — Reverse Pipeline Reasoning

The following values are observed for one instruction:

EX:  ALU Result = 0x10010014
MEM: Memory Read Data = 0x00000064
WB:  $t5 receives 0x00000064

Assume $s0 = 0x10010000. Determine the instruction type, destination register, and immediate offset.

Write the complete MIPS instruction.

Answer

Instruction: lw $t5, 20($s0)

Offset = 0x14 = 20; destination register = $t5.

Key Point:

EX, MEM, and WB results can reveal the original load instruction.
