## Slide 19 — Pipeline Stage Occupancy

Q4. Consider an ideal 5-stage MIPS pipeline (IF, ID, EX, MEM, WB) with no stalls.

Instruction I1 enters the IF stage at CC1, and each subsequent instruction enters IF one cycle later.

If I3 is in the MEM stage, determine the current clock cycle and the stage occupied by I5.

A4.

I3 enters IF at CC3.

I3 reaches MEM three cycles later, at CC6.

I5 enters IF at CC5 and reaches ID at CC6.

Therefore:

Clock Cycle = CC6; I5 is in the ID stage.

## Slide 24 — Exercise 1 — Load and Store Datapath Tracing

Exercise 1 — Load and Store Datapath Tracing

Consider the following MIPS instructions:

I1: lw $t0, 8($a0)

I2: sw $t1, 12($a1)

Register / Memory

Value

$a0

0x10010000

$a1

0x10020000

$t1

0xABCDEF12

Mem[0x10010008]

0x12345678

(a) Calculate the effective address of each instruction.

(b) Determine the ALU result and store data in the EX/MEM register for I2.

(c) Determine the MEM operation and WB result of each instruction.

Answer

(a) Effective Addresses

- I1: 0x10010000 + 8 = 0x10010008
- I2: 0x10020000 + 12 = 0x1002000C
(b) EX/MEM Values for I2

- ALU result = 0x1002000C
- Store data = 0xABCDEF12
(c) MEM and WB Operations

- I1 (MEM): Read Mem[0x10010008] = 0x12345678
- I1 (WB): $t0 ← 0x12345678
- I2 (MEM): Mem[0x1002000C] ← 0xABCDEF12
- I2 (WB): No register write
Key Point:

The EX stage calculates effective addresses, while MEM and WB stages perform instruction-specific operations.


## Slide 25 — Exercise 2 — Multi-Cycle Pipeline Diagram

Exercise 2 — Multi-Cycle Pipeline Diagram

Consider the following instructions in an ideal 5-stage MIPS pipeline (IF, ID, EX, MEM, WB), without stalls.

I1: lw  $t0, 0($a0)

I2: add $t1, $t2, $t3

I3: sub $t4, $t5, $t6

I4: lw  $t7, 8($a0)

I5: add $s0, $s1, $s2

(a) How many instructions are active in the pipeline at CC4?

(b) At which clock cycle does I3 complete the WB stage?

(c) How many clock cycles are required to complete all five instructions?

Answer

(a) 4 instructions (I1–I4).

(b) CC7.

(c) 9 clock cycles.

Key Point:

In an ideal 5-stage pipeline, completing N instructions requires N + 4 clock cycles.

## Slide 27 — Exercise 3 — Answer

Exercise 3 — Answer

(a) Pipeline Register Contents at CC5

ID/EX

I3: add $12, $3, $4

EX/MEM

I2: sub $11, $2, $3

MEM/WB

I1: lw $10, 20($1)

(b) ALU Result Transfer

I3 computes $3 + $4 in EX. The result is captured in EX/MEM at the end of CC5.

(c) Register Write-Back

I1 (lw) writes memory-read data from MEM/WB into register $10.

Key Point:

Different instructions occupy different stages and use distinct data paths.
