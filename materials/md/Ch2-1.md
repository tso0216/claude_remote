§2.1 Introduction

## Slide 4 — Arithmetic Operations

§2.2 Operations of the Computer Hardware

- Add and subtract, three operands
  - Two sources and one destination
add a, b, c  # a gets b + c

- All arithmetic operations have this form
- Design Principle 1: Simplicity favors regularity
  - Regularity makes implementation simpler
  - Simplicity enables higher performance at lower cost

## Slide 6 — Register Operands

§2.3 Operands of the Computer Hardware

- Arithmetic instructions use register
  operands
- MIPS has a 32 × 32-bit register file
  - Use for frequently accessed data
  - Numbered 0 to 31
  - 32-bit data called a “word”
- Assembler names
  - $t0, $t1, …, $t9 for temporary values
  - $s0, $s1, …, $s7 for saved variables
- Design Principle 2: Smaller is faster
  - c.f. main memory: millions of locations

## Slide 8 — Memory Operands

- Main memory used for composite data
  - Arrays, structures, dynamic data
- To apply arithmetic operations
  - Load values from memory into registers
  - Store result from register to memory
- Memory is byte addressed
  - Each address identifies an 8-bit byte
- Words are aligned in memory
  - Address must be a multiple of 4
- MIPS is Big Endian
  - Most-significant byte at least address of a word
  - c.f. Little Endian: least-significant byte at least address

## Slide 9 — Memory Operand Example 1

- C code:

  - g in $s1, h in $s2, base address of A in $s3
- Compiled MIPS code:
  - Index 8 requires offset of 32
    - 4 bytes per word
lw  $t0, 32($s3)    # load word
add $s1, $s2, $t0

## Slide 12 — Immediate Operands

- Constant data specified in an instruction
addi $s3, $s3, 4

- No subtract immediate instruction
  - Just use a negative constant
  addi $s2, $s1, -1

- Design Principle 3: Make the common case fast
  - Small constants are common
  - Immediate operand avoids a load instruction

## Slide 13 — The Constant Zero

- MIPS register 0 ($zero) is the constant 0
  - Cannot be overwritten
- Useful for common operations
  - E.g., move between registers
  add $t2, $s1, $zero

Q8. Assume: $s1=15, $t0=8 Execute the following instructions in order:

add $t1, $s1, $zero

add $zero, $t0, $s1

add $t2, $zero, $t0

(a) What is the final value of $t1?

(b) What is the final value of $zero?

(c) What is the final value of $t2?

A8.

(a) $t1 = 15, because $zero always provides the value 0.

(b) $zero=0. Writing a result to $zero doesn’t change its value.

(c) $t2 = 8, $zero is still 0 after the second instruction.

## Slide 16 — Exercise 1 | Arithmetic & Register Operands

Exercise 1 | Arithmetic & Register Operands

Assume: f → $s0, g → $s1, h → $s2, i → $s3, j → $s4
Translate the C statement into MIPS instructions:
f = (g − h) + (i + j) − g

(a) Write the MIPS instruction sequence using $t0, $t1, … as needed.
(b) If $s1 = 8, $s2 = 3, $s3 = 6, and $s4 = 4, find the final value of $s0.

Answer

(a) sub $t0, $s1, $s2

add $t1, $s3, $s4

add $t0, $t0, $t1

sub $s0, $t0, $s1

(b) $t0 = 8 − 3 = 5,  $t1 = 6 + 4 = 10

$t0 = 5 + 10 = 15,  $s0 = 15 − 8 = 7

Key Point: Complex expressions are decomposed into simple MIPS arithmetic instructions, with intermediate results stored in temporary registers.


## Slide 17 — Exercise 2 | Register Value Tracking

Exercise 2 | Register Value Tracking

Assume: $s0 = 12, $s1 = 5, $s2 = 8.
Execute the following instructions in order:
add $t0, $s0, $s1
sub $t1, $t0, $s2
add $t2, $t1, $s1
sub $s3, $t2, $t0
(a) Determine the final values of $t0, $t1, $t2, and $s3.
(b) Which registers contain intermediate results?

Answer

(a) $t0 = 12 + 5 = 17

$t1 = 17 − 8 = 9

$t2 = 9 + 5 = 14

$s3 = 14 − 17 = −3

(b) $t0, $t1, and $t2 contain intermediate results.

Key Point: MIPS instructions execute sequentially, and later instructions can use results produced by earlier instructions.


## Slide 18 — Exercise 3 | Array Addressing and Memory Access

Exercise 3 | Array Addressing and Memory Access

Assume $s3 = 2000 contains the base address of integer array A.
Each element is one word (4 bytes).

(a) Calculate the byte offsets of A[5] and A[9].
(b) Calculate their effective memory addresses.
(c) Write MIPS instructions to load A[5] into $t0 and A[9] into $t1.

Answer

(a) A[5]: 5 × 4 = 20 bytes

A[9]: 9 × 4 = 36 bytes

(b) Address of A[5] = 2000 + 20 = 2020

Address of A[9] = 2000 + 36 = 2036

(c) lw $t0, 20($s3)

lw $t1, 36($s3)

Key Point: For a word array, byte offset = array index × 4, and effective address = base address + offset.


## Slide 19 — Exercise 4 | Load–Operate–Store

Exercise 4 | Load–Operate–Store

Assume $s3 contains the base address of integer array A.
h is stored in $s2, $s2 = 6, and A[3] = 10.
Translate:  A[7] = A[3] − h
(a) Calculate the required byte offsets.
(b) Write the MIPS instruction sequence.
(c) Determine the final value of A[7].

Answer

(a) A[3]: 3 × 4 = 12 bytes

A[7]: 7 × 4 = 28 bytes

(b) lw  $t0, 12($s3)

sub $t0, $t0, $s2

sw  $t0, 28($s3)

(c) A[7] = 10 − 6 = 4

Key Point: Load memory data into a register, perform arithmetic on registers, then store the result back to memory.


## Slide 20 — Exercise 5 | Integrated MIPS Analysis

Exercise 5 | Integrated MIPS Analysis

Assume $s3 contains the base address of integer array A,

A[2] = 9, and $s1 = 5.
Execute:
lw   $t0, 8($s3)
addi $t0, $t0, 4
add  $t1, $t0, $s1
add  $s2, $t1, $zero
sw   $s2, 16($s3)

(a) What value is loaded into $t0?
(b) Find the final values of $t0, $t1, and $s2.
(c) Which array element is modified, and what is its final value?
(d) Identify the immediate operand and explain the role of $zero.

Answer

(a) $t0 = A[2] = 9

(b) $t0 = 9 + 4 = 13;  $t1 = 13 + 5 = 18;  $s2 = 18

(c) 16 ÷ 4 = 4, so A[4] = 18

(d) Immediate operand: 4.  $zero always supplies 0, so

add $s2, $t1, $zero copies the value in $t1 to $s2.

Key Point: MIPS combines register operations, memory accesses, immediate constants, and $zero to implement complex computations.
