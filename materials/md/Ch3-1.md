## Slide 10 — CPU Overview

Q2. The CPU overview showed how the processor executes the instruction:

add $t0, $t1, $t2

The execution can be summarized in five steps:

1. Fetch the instruction

2. Decode the instruction

3. Read the registers

4. Execute and write back

5. Update the PC

If the instruction is changed to sub $t0, $t1, $t2, which steps remain the same, and which step changes?

A2.

Step 4 changes: ALU operation: ADD → SUB. The processor can reuse the same basic datapath, but the ALU performs a different operation.

Q3.

(a) If the instruction is changed to lw $t0, 8($t1), which additional component is used, and why?

(b) If the instruction is changed to a branch instruction, which additional component is used, and why?

A3.

(a) Data Memory is additionally used.

(b) The second Add unit calculates the branch target address using PC + 4 and the branch offset.

## Slide 21 — Exercise 1 | Trace an Instruction

Exercise 1 | Trace an Instruction

Consider:  sub  $t0, $t1, $t2

Assume $t1 = 25, $t2 = 9, and PC = 0x00400020.

(a) Trace the major execution steps and identify the CPU component used.

(b) Determine the value written to $t0.

(c) Determine the next PC value.

Answer

(a)

PC → Instruction Memory → Register File → ALU → Register File → PC update

Register File reads $t1 = 25 and $t2 = 9.

ALU performs subtraction and the result is written back to $t0.

(b) $t0 = 25 − 9 = 16

(c) Next PC = 0x00400020 + 4 = 0x00400024

Trace an instruction by following data through the major CPU components.

## Slide 23 — Exercise 3 | Datapath Selection and Control

Exercise 3 | Datapath Selection and Control

A processor shares one datapath among different instructions:

add  $t0, $t1, $t2      lw  $t0, 8($t1)      beq  $t0, $t1, Label

(a) Identify the main ALU role for each instruction.

(b) Determine whether Data Memory and the branch-target Add unit are needed.

Answer

(a) add: add register values

lw: calculate address

beq: compare registers

(b) add: neither   |   lw: Data Memory   |   beq: branch-target Add

Key Point:

MUXes and control signals let different instructions share the same datapath.
