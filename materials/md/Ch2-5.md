## Slide 20 — Exercise 1 | Byte Memory Operations

Exercise 1 | Byte Memory Operations

Given: $s0 = 0x1000

Memory[0x1000] = 1110 0010     Memory[0x1001] = 0011 0101

$t0 = 10101010 11001100 11110000 00001111

Determine independently:

(a) lb $t1, 0($s0)

(b) lbu $t1, 0($s0)

(c) sb $t0, 1($s0)

Answer

(a) $t1 = 11111111 11111111 11111111 11100010

(b) $t1 = 00000000 00000000 00000000 11100010

(c) Memory[0x1001] = 00001111

Key Point: lb uses sign extension, lbu uses zero extension, and sb stores only the rightmost 8 bits.


## Slide 21 — Exercise 2 | Branch Addressing and Encoding

Exercise 2 | Branch Addressing and Encoding

A MIPS bne instruction is at address 2400 and branches to target 2320.

(a) Calculate the 16-bit branch offset.

(b) Is the offset positive or negative? Explain briefly.

(c) For bne $t0, $s1, Target, identify op, rs,  rt, constant/address.

Answer

PC used = 2400 + 4 = 2404

offset = (2320 − 2404) / 4 = −84 / 4 = −21

(a) offset = −21

(b) Negative; the target is before the branch instruction.

(c) op = bne, rs = $t0, rt = $s1, constant/address = −21

Key Point: A branch offset is measured from PC + 4 in instruction words; a backward branch therefore uses a negative offset.

(b) Why can the other target not be represented?

(c) For the valid target, identify the 26-bit address field.

Answer

PC[31:28] = 0010; Target A[31:28] = 0010; Target B[31:28] = 0011

(a) Target A

(b) Target B cannot be represented because its upper 4 bits differ from PC[31:28]

(c) 26-bit address field = 00000000000000000001000000

Key Point: A pseudodirect jump reuses PC[31:28], so a direct j target must have the same upper 4 bits as the current PC.
