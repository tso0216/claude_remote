## Slide 15 — Non-Leaf Procedures

## Slide 16 — Non-Leaf Procedure Example

- C code:
int fact (int n)
{
  if (n < 1) return 1;
  else return n * fact(n - 1);
}

  - Argument n in $a0
  - Result in $v0

## Slide 17 — Non-Leaf Procedure Example

- MIPS code:
fact:
    addi $sp, $sp, -8     # adjust stack for 2 items
    sw   $ra, 4($sp)      # save return address
    sw   $a0, 0($sp)      # save argument
    slti $t0, $a0, 1      # test for n < 1
    beq  $t0, $zero, L1
    addi $v0, $zero, 1    # if so, result is 1
    addi $sp, $sp, 8      #   pop 2 items from stack
    jr   $ra              #   and return
L1: addi $a0, $a0, -1     # else decrement n
    jal  fact             # recursive call
    lw   $a0, 0($sp)      # restore original n
    lw   $ra, 4($sp)      #   and return address
    addi $sp, $sp, 8      # pop 2 items from stack
    mul  $v0, $a0, $v0    # multiply to get result
    jr   $ra              # and return

Exercise 1 | Procedure Calling and Register Usage

Consider the following C function call:   result = compute(8, 3);
Assume compute uses temporary values internally and returns one integer.
(a) Which MIPS registers are normally used to pass 8 and 3 to the procedure?
(b) Which register is normally used to return result?
(c) If temporary values do not need to be preserved after the call, which registers should be used?

Answer

(c) $t0–$t9 can be used for temporary values.

## Slide 24 — Exercise 2 | Trace a Leaf Procedure

Exercise 2 | Trace a Leaf Procedure

Consider the following MIPS procedure:
Initially: $a0=12, $a1=7, $a2=5, $s0=40, $sp=1000

addi $sp, $sp, -4

sw $s0, 0($sp)
add  $t0, $a0, $a1

sub $s0, $t0, $a2
add  $v0, $s0, $zero

lw  $s0, 0($sp)

addi $sp, $sp, 4

jr  $ra
(a) Find $t0 and $v0.

(b) Find the final $s0 and $sp.

Answer

$t0 = 12 + 7 = 19;   $v0 = 19 - 5 = 14

(b) Final $s0 = 40;   final $sp = 1000

Key Point: A callee may use a saved register, but it must restore the register before returning.

## Slide 26 — Exercise 4 | Trace Recursive Stack Usage

Exercise 4 | Trace Recursive Stack Usage

Using the fact procedure from the lecture, assume fact(4) is called and $sp=1000 initially.
(a) List the values of $a0 as the recursive calls descend to the base case
(b) What is the minimum value reached by $sp before the recursion begins returning?
(c) What are the final values of $v0 and $sp after fact(4) completes?

Answer

$a0: 4 → 3 → 2 → 1 → 0
Five active calls are created: fact(4) through fact(0).

(b) Each call allocates 8 bytes: 1000 - 5 × 8 = 960.

(c) $v0 = 4 × 3 × 2 × 1 = 24;   final $sp = 1000.

Key Point: Each recursive call creates a new stack frame, causing the stack to grow until the base case is reached.
