## Slide 6 — Measuring Execution Time

- Elapsed time
  - Total response time, including all aspects
    - Processing, I/O, OS overhead, idle time
  - Determines system performance
- CPU time
  - Time spent processing a given job
    - Discounts I/O time, other jobs’ shares
  - Comprises user CPU time and system CPU time
  - Different programs are affected differently by CPU and system performance
Q5. A program has an elapsed time of 20 s but uses only 5 s of CPU time. Would a 2× faster CPU reduce the elapsed time to 10 sec?

A5. No. Elapsed time should be 5/2+(20−5)=17.5 sec	​

## Slide 14 — Exercise 2 | Response Time vs. Throughput

Exercise 2 | Response Time vs. Throughput

A web service is upgraded. Before the upgrade, each request takes 4 s and the server completes 120 requests/min. After the upgrade, each request still takes 4 s, but the server completes 240 requests/min.

Which performance metric improved? By how much?

Answer

Response time: unchanged at 4 s/request.

Throughput: 120 → 240 requests/min = 2× throughput (100% increase).

Therefore, the upgrade improves throughput, not response time.

Key Point: Higher throughput does not necessarily mean a shorter response time.


## Slide 15 — Exercise 3 | Relative Performance

Exercise 3 | Relative Performance

Computer A is 50% faster than Computer B. Computer B executes a program in 18 s.

1. How many times faster is A than B?

2. What is A’s execution time?

3. Is A’s execution time 50% shorter than B’s?

Answer

- 50% faster = 1.5× performance.
- T_A = 18 / 1.5 = 12 s.
- No. The reduction is (18 − 12) / 18 = 33.3%.
Key Point: A percentage increase in performance is not the same percentage decrease in execution time.


## Slide 16 — Exercise 4 | Elapsed Time vs. CPU Time

Exercise 4 | Elapsed Time vs. CPU Time

A program has an elapsed time of 30 s, including 12 s of CPU time. The CPU is replaced by one that executes the CPU portion 3× as fast. Assume all non-CPU time is unchanged.

What is the new elapsed time?

Answer

Non-CPU time = 30 − 12 = 18 s

New CPU time = 12 / 3 = 4 s

New elapsed time = 4 + 18 = 22 s

Key Point: Speeding up the CPU affects only the CPU portion of elapsed time.

## Slide 18 — Exercise 5 | Integrated Performance Analysis — Answer

Exercise 5 | Integrated Performance Analysis — Answer

Answer

1. Response time: System B is better. 12 / 8 = 1.5× the response-time performance of A.

2. Throughput: (150 − 100) / 100 × 100% = 50% improvement.

3. CPU performance: P_B / P_A = T_A / T_B = 8 / 5 = 1.6×.

4. No. Non-CPU time also improves:

System A: 12 − 8 = 4 s    |    System B: 8 − 5 = 3 s

Both CPU time and non-CPU time are reduced.

Key Point: Response time, throughput, relative performance, and CPU time describe different aspects of system performance.
