# 辯論紀錄

三位辯手各持一個立場，經三回合辯論後由主持人整合。定案見上一層的 [`README.md`](../README.md)。

| 辯手 | 第一回合立場 |
|---|---|
| A | 結構化時空知識庫派：開放資料 → 知識庫 → 程式算答案（推薦臺灣） |
| B | 群體軌跡派：從照片與遊記萃取旅客軌跡，答案是附 n 與 CI 的統計量（推薦京都） |
| C | 真實問題與網路文本派：從論壇真實提問出發，標註可執行表示後由程式算答案（推薦關西） |

| 檔案 | 內容 |
|---|---|
| `r1-A.md`、`r1-B.md`、`r1-C.md` | 第一回合：立論（題目、資料來源、題型、系統、相關研究） |
| `r2-A.md`、`r2-B.md`、`r2-C.md` | 第二回合：交叉質詢、讓步與修正後的推薦 |
| `moderator-draft-v1.md` | 主持人整合草案（地區暫定臺灣） |
| `r3-A.md`、`r3-B.md`、`r3-C.md` | 第三回合：對草案的表決、題型壓力測試、稀有度與資料來源更正 |

紀錄中的「已查證」指辯手當時用網路搜尋確認過。辯論環境連不到 data.gov.tw、TDX、PTT、arXiv，所以部分細節只能透過搜尋結果核對，正式使用前請自行下載確認。
